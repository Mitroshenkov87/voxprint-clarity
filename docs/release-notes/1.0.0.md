# VOXPrint AI Clarity 1.0.0

Clarity is non-generative video cleanup. It denoises, deblocks, sharpens,
and cleans colour on the frames you already have. Optional 2x upscale stays
off unless you turn it on. The default output is AV1, and the audio is
passed through.

## Requirements

- Windows 11 (24H2 or newer) or Linux
- An NVIDIA RTX 40-series GPU or newer
- A current NVIDIA driver (600 series or newer)

## Install

The Windows installer is `voxprint-clarity-setup-1.0.0-win-x64.exe`.
It installs into `C:\Program Files\VOXPrint AI Suite\Clarity`.

The Linux package is `voxprint-clarity_1.0.0_linux-x64.tar.gz`.
It installs into `/opt/voxprint-ai-suite/clarity`.

The Windows installer is not code-signed.

## Check the download

`SHA256SUMS` in this release lists the published files under those names.
From the folder that contains the files and `SHA256SUMS`:

```bash
sha256sum -c SHA256SUMS
```

On Windows PowerShell:

```powershell
Get-FileHash .\voxprint-clarity-setup-1.0.0-win-x64.exe -Algorithm SHA256
```

The digest must match the line for that file in `SHA256SUMS`.
